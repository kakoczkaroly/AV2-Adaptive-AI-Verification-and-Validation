# Visual demos

- [Continuous release stream](av2-release-stream.html): two independent strands, six separate release rounds, and overlapping production observation. Toggle the held round: an affected candidate stops but the stream continues.
- [Inside one turn](av2-loop.html): watch proposal challenge, early feedback, confirmation and regression. Try the regression and stale-evidence scenarios.

Open each GitHub file, select **Download raw file**, then open it locally. These are deterministic visual simulations, not live integrations. For a command-line run against product fixtures, use the [local prototype](../framework/README.md).
